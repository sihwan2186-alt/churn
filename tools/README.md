# Tools

프로젝트 본 실험 스크립트가 아니라, 산출물 정리나 보조 작업에 쓰는 도구를 둔 폴더입니다.

| 위치 | 역할 |
| --- | --- |
| `presentation/polish_churnradar_presentation.py` | 상세 PPT 문구를 발표용으로 정리하고 슬라이드별 발표자 노트를 삽입 |

실행:

```powershell
.\.venv\Scripts\python.exe -u tools\presentation\polish_churnradar_presentation.py
```

입력 PPT와 출력 PPT는 `deliverables/presentations/`를 사용합니다.
